How to Connect MongoDB Atlas:

  1. Apne project folder mein .env file open karein.
  2. MONGODB_URI mein apna password aur cluster domain update karein:
MONGODB_URI=mongodb+srv://pk6926459_db_user:<PASSWORD>@<YOUR_CLUSTER_HOST>/localkart?retryWrites=true&w=majority

💡 Note: Agar MongoDB offline rehta hai, tab bhi website aur booking 100% chalti rahegi automatically local JSON storage se!
